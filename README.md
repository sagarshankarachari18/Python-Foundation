# 📊 Python Foundation: CLI Expense Tracker

A lightweight, terminal-based financial logging script built to master core Python programming structures, data types, and system flows.

## 🚀 Key Features Implemented
- **Infinite Application Loops:** Uses persistent `while` structures to process continuous user input commands.
- **Dynamic Data Storing:** Leverages Python `Lists` and key-value `Dictionaries` to structure memory tables.
- **Automated Formatting:** Formats floating-point numbers seamlessly into currency styles (`:.2f`).

## 🛠️ Built With
- **Language:** Python 3.x
- **Interface:** Command-Line Interface (CLI)

## 💻 How to Run It
Make sure you have Python installed, then run the script via your terminal:
```bash
python tracker.py
```
