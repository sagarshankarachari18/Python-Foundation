# Python Foundation: CLI Expense Tracker

A lightweight, terminal-based financial logging application built to master core Python programming structures, data handling, and input validation.

---

## Key Features

- **Infinite Application Loop:** Uses persistent `while` structures for interactive command selection.
- **Input Validation & Crash Prevention:** Guarantees numerical inputs using `try-except` blocks to handle invalid entries cleanly.
- **Data Persistence:** Automatically saves and loads expenses to a local file (`expenses.txt`) using relative file paths.
- **Automated Currency Formatting:** Formats amounts into standard euro currency layout (`€X.XX`).

---

##  Tech Stack

- **Language:** Python 3.x
- **Storage:** Text File I/O (`expenses.txt`)
- **Interface:** Command-Line Interface (CLI)
